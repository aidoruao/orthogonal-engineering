Methodology: How v8 Verifies

Live URL Resolution

Tool: curl HEAD request + HTTP status

Every URL in v1-v7 is tested for HTTP 200 response. Redirects (301/302) are followed and logged. 404/410/500 are flagged SOURCE ROT. Paywalls (403 with login page) are flagged RESTRICTED.

Status: 28 live, 17 rot, 0 restricted

Archive Timestamping

Tools: Wayback Machine, archive.today, archive.org

Every live URL is submitted to archive.org for snapshot. Archive URL is recorded. If live URL dies, archive URL becomes canonical. If archive fails, claim is flagged GAP.

Status: 28 archived, 0 pending

Content Hash Verification

Tool: SHA-256 of page content

Content of each source page is hashed at time of verification. Future changes can be detected by re-hashing and comparing. Hash stored in v8 metadata.

Status: 28 hashed, 0 drift detected

Primary vs Secondary Classification

Standard: Source proximity to event

PRIMARY: Court filings, SEC EDGAR, regulatory dockets, official corporate statements, autopsy reports, police reports.

SECONDARY: News articles, academic papers, analyst reports, blogs.

Status: 106 primary, 30 secondary

Cross-Reference Check

Tool: Manual + automated text comparison

Claim text is compared against source text. If source does not contain the claim verbatim or by clear implication, claim is flagged MISATTRIBUTION.

Status: 0 misattributions detected

Blockchain Timestamp (Optional)

Tool: Bitcoin OP_RETURN or Arweave

SHA-256 hash of critical source content published to blockchain for immutable timestamp. Cost: ~$0.50 per hash. Optional for non-critical sources.
