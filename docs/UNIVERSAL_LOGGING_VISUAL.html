UNIVERSAL LOGGING FIX

One Import Module to Fix All Unicode Errors

v0.4.2 - Indefinite Solution

❌ The Problem

Every pipeline script handled logging differently:

  • Some forgot encoding='utf-8'
  • Some used Unicode console output (⚠, ✅, 🤖)
  • Some had no logging at all
  • Random Unicode errors across scripts
print(f"⚠ Warning")
UnicodeEncodeError: 'charmap' codec can't encode character '\u26a0'

✅ The Solution

PIPELINE_LOGGER.py - Single Import Module

Every script imports the same logging configuration:

from PIPELINE_LOGGER import logging, safe_print

# Detailed Unicode logging (to file)
logging.info(f"Reading {unicode_filename}...")

# Console status (ASCII-safe)
safe_print("[SUCCESS] Complete")

How PIPELINE_LOGGER.py Works

# PIPELINE_LOGGER.py
import logging

# Configure ONCE - applies to ALL imports
logging.basicConfig(
    filename='pipeline_run_log.txt',
    level=logging.INFO,
    encoding='utf-8',  # CRITICAL
    format='%(asctime)s - %(message)s'
)

def safe_print(message):
    """Handle Unicode gracefully for console"""
    try:
        print(message)
    except UnicodeEncodeError:
        print(message.encode('ascii', errors='ignore').decode('ascii'))
