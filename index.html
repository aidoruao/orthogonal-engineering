@validator('query')
def validate_sql(cls, v):
    # Basic SQL injection prevention
    forbidden = ['DROP', 'DELETE', 'TRUNCATE']
    if any(word in v.upper() for word in forbidden):
        raise ValueError('Unsafe SQL operation')
    return v

Methodology

You are not fixing the model. You are engineering around its nature by designing prompts that anticipate and route slack, using iterative refinement to collapse noise progressively, separating invariant extraction from generative acts, and treating LLM verbosity not as a bug but as a predictable force to be channeled.
