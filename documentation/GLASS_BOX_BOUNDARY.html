2. Atomic Implementation Steps (v1.10) 
PHASE 1-8: Same as v1.8

PHASE 9: Meta-Validation + Enforcement
- Crawl repository for required artifacts (pipeline.ps1, validator.py, GLASS_BOX_BOUNDARY.html, etc.)
- Record missing/corrupted files in repository_meta.artifact_validation_errors
- Snapshot environment (Python version, pip freeze)
- Capture AI suppressed signals and append to suppressed_signals
- Track timeline start/end; inject timeline_errors for sequence violations
- Compute hash_manifest of evidence_map + environment snapshot
- Sign the trace with private key (immutable)

PHASE 10: Hard Enforcement
- Exit with code 2 if any:
  - len(trace.timeline_errors) > 0
  - len(trace.repository_meta.artifact_validation_errors) > 0
  - len(trace.suppressed_signals) > 0
- Store signed JSON trace in traces/
- All automation tools (IDE, scripts, Zed AI) reference this HTML for instructions

PHASE 11: IDE / Automation Integration
- Zed IDE or any automation reads this HTML
- Generates instructions for Python wrapper implementation
- Ensures all invariant and enforcement steps are captured
