Layer 3 — Atomic Execution Instructions (Zed IDE)

PHASE 1 — Freeze State (Replayability) 
Goal: Ensure deterministic replay.

1. Pull latest repository state
2. Confirm clean working tree
3. Record current commit hash
4. Pin Python + dependencies (requirements.txt) for reproducibility

Commands:
git status
git rev-parse HEAD

STOP if working tree is dirty.

Create file:
/specs/EPISTEMIC_TRACE_SCHEMA.json

  "active_ontology": "string",
  "ontology_candidates": ["string"],

    "ontology_name": ["file_path"]

PHASE 3 — Wrap full_audit.py (No Refactor) 
Create wrapper:
/automation/run_full_audit_with_trace.py

Responsibilities:
1. Capture commit hash + timestamp + python_env
2. Execute full_audit.py
3. Intercept:
   - ontology selection
   - grounding assumptions (Gₛ)
4. Emit epistemic_trace.json including new fields
5. Hash trace (hash_manifest)
6. Sign trace (optional)
7. Store alongside audit output

Rule:
If trace generation fails → audit FAILS.
PHASE 4 — Modify full_audit.py (Surgical) 
Do NOT change logic.

Add hooks only:
- Function returns:
  - detected ontology signals
  - suppressed signals (if any)
- No printing
- Structured return for wrapper

Backward compatibility preserved.

Rule:
Any script under /automation must:
