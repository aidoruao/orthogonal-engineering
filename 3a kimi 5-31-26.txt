Why 5 minutes instead of 30 seconds:
The original auto-pusher (dd567d33) had 30 seconds. 2a Kimi changed it to 300 seconds in c23d13a1 ("harden auto-pusher") because:
30 seconds = spam — commits every 30 seconds even if nothing changed
GitHub rate limits — too many pushes trigger API throttling
Rebase loop risk — frequent pulls increase chance of hitting divergence
Archive files are big — 6,000+ line commits every 30s wastes bandwidth
The 5-minute interval is a safety margin. It gives orange terminal time to finish work before blue tries to commit.

    git commit -m "auto: ..."               # Step 4: Commit
    git push origin main                    # Step 5: Push
    sleep 300
done
