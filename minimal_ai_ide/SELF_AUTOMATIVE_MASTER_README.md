## 🛠️ Installation & Setup

### Prerequisites
- Windows 10/11 with WSL2 enabled OR Linux system
- Python 3.11+
- 8GB+ RAM (16GB recommended for model training)
- NVIDIA GPU (optional, for accelerated training)

### Quick Start (WSL2)

```bash
# Clone or navigate to the project
cd minimal_ai_ide

# Make the setup script executable
chmod +x SELF_AUTOMATIVE_MASTER_WSL2.sh

# Run full setup (first time)
./SELF_AUTOMATIVE_MASTER_WSL2.sh --setup

# Or use interactive menu
./SELF_AUTOMATIVE_MASTER_WSL2.sh --menu
```

## 🚨 Troubleshooting

### Common Issues

1. **WSL2 not detected**
   ```bash
   # Check WSL2 installation
   wsl --list --verbose
   
   # Enable systemd
   sudo nano /etc/wsl.conf
   # Add: [boot] systemd=true
   ```

2. **Python package conflicts**
   ```bash
   # Recreate virtual environment
   rm -rf venv_wsl2
   python3.11 -m venv venv_wsl2
   source venv_wsl2/bin/activate
   pip install -r requirements_v57_lora.txt
   ```

3. **Σ_LORA constraint violations**
   ```bash
   # Check constraint definitions
   python SELF_AUTOMATIVE_MASTER_COMPLETE.py --test-constraints
   
   # Review Christ Score
   grep "Christ Score" logs/system.log
   ```

4. **Model loading failures**
