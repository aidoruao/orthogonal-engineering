## 🔄 HOW IT WORKS

### **Step-by-Step Flow:**
1. User types: `brain "dig a 3x3 room"`
2. Lua bridge sends command to constraint server
3. Server validates against all 6 Σ_LORA constraints
4. If valid: Generates Lua code via DeepSeek API
5. Code validated for safety (no infinite loops, etc.)
6. Returns validated Lua code to ComputerCraft
7. User confirms execution (y/n)
8. Turtle executes constraint-compliant code

### **Constraint Scoring:**
Each command receives a "Christ score" (0.0-1.0):
- 1.0 = Perfect compliance with all 6 constraints
- 0.7 = Minimum threshold for execution
- <0.7 = Command rejected
