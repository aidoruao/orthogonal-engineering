API Endpoints

GET /api/data.json

Returns complete repository state including domain count, case studies, and current Merkle root.

{
  "domains": 158,
  "domains_deepened": 158,
  "case_studies": 182,
  "kernel_modules": 20,
  "merkle_root": "a1b2c3d4...",
  "generated": "2026-04-11T04:30:00Z"
}
GET /api/domains

List all domains with their invariant status.

{
  "count": 158,
  "domains": [
    {"id": "D_GUARDIAN", "name": "Operation T-800 Guardian", "status": "deepened"},
    {"id": "D_COMMONWEALTH", "name": "Yeshua Commonwealth", "status": "deepened"}
  ]
}
GET /api/invariants/{domain}

Get invariants for a specific domain (e.g., /api/invariants/D_GUARDIAN).

{
  "domain": "D_GUARDIAN",
  "invariants": [
    "Exactly one guardian per principal",
    "Guardian heartbeat within configured interval",
    "Force used never exceeds proportional budget"
  ]
}
GET /api/case-studies

List all case studies with category distribution.

{
  "count": 182,
  "categories": {
    "AI_FAILURES": 20,
    "INFRASTRUCTURE": 20,
    "PRIVACY": 10,
    "FINANCIAL_FRAUD": 10,
    "LABOR": 10
  }
}
GET /api/merkle-root

Get current repository Merkle root.

{
  "merkle_root": "a1b2c3d4e5f6789...",
  "timestamp": "2026-04-11T04:30:00Z",
  "files_hashed": 500
}
POST /api/verify-proof

Verify a ProofObject hash against the witness chain.

// Request
{
  "proof_hash": "sha256:abc123...",
  "context": "guardian_protection_record_001"
}

// Response
{
  "valid": true,
  "witnessed_at": "2026-04-11T04:30:00Z",
  "witness_node": "witness-001"
}
